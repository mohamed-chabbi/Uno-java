# UNO Java Game

## Description
A console-based implementation of the UNO card game developed in Java using Object-Oriented Programming (OOP). The project models the main components of the game such as cards, players, and game flow.

---

## Features
- Card system (colors and values)
- Multiple players
- Turn-based gameplay
- Basic rule handling

---

## Project Structure
- `Card.java` → card representation  
- `Deck.java` → deck management  
- `Player.java` → player logic  
- `Game.java` → game flow  
- `Main.java` → program entry point  

---

## How to Run
```bash
javac *.java
java Main
