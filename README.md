# UNO Java Game

## Description
A console-based UNO game implemented in Java using Object-Oriented Programming (OOP) principles.  
This project simulates the core mechanics of the UNO card game including players, deck management, and game rules.

---

## Features
- Multiple players
- Card system (number and special cards)
- Turn-based gameplay
- Basic rule enforcement

---

## Project Structure
- `Card.java` → represents a card
- `Deck.java` → manages the deck
- `Player.java` → represents a player
- `Game.java` → handles game logic
- `Main.java` → entry point

---

## How to Run

```bash
javac *.java
java Main
